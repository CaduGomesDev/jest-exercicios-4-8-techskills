# Jest - exercícios 4 a 8

Minhas respostas aos exercícios de testes com Jest: erros com `toThrow`, organização dos arquivos, integração com supertest, mocks com `jest.fn()` e cobertura. Feito em TypeScript com ts-jest.

## Rodar

```
npm install
npm test
npm test -- --coverage
```

## O que tem aqui

| Exercício | Onde |
|---|---|
| 4 - Erros | `src/divide.ts` |
| 5 - Estrutura | `src/formatador.ts` e a pasta `__tests__` |
| 6 - Integração | `src/app.ts` com a rota `/ping` |
| 7 - Mocks | `src/usuarioService.ts` |
| 8 - Cobertura | `jest.config.js` e `respostas/cobertura` |

As respostas escritas de cada exercício estão na pasta [respostas](respostas).
